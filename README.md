📊 Estudos em Análise de Dados

Repositório destinado aos meus estudos e projetos práticos em Análise de Dados, realizados durante minha formação na Alura e na Data Science Academy (DSA).

O objetivo deste repositório é registrar minha evolução em análise, tratamento, exploração e visualização de dados, aplicando diferentes ferramentas e técnicas em exercícios e projetos práticos.

🎯 Objetivos
Desenvolver conhecimentos em Análise de Dados;
Aprimorar a interpretação e exploração de dados;
Praticar tratamento e transformação de dados;
Desenvolver dashboards e relatórios;
Trabalhar com Power BI e Power Query;
Aprender e aplicar DAX;
Praticar SQL e Python para análise de dados;
Desenvolver projetos práticos para consolidar os conhecimentos adquiridos.
